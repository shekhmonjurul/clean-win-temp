# 🧹 Windows Temp & Prefetch Cleaner

আপনার উইন্ডোজ পিসির অপ্রয়োজনীয় ফাইল (Temp এবং Prefetch) এক ক্লিকে মুছে ফেলে পিসিকে আরও ফাস্ট করার জন্য এটি একটি সহজ পাইথন টুল।

## ✨ বৈশিষ্ট্য
*   `%temp%` (User Temp) ফোল্ডার ক্লিন করে।
*   `C:\Windows\Temp` (System Temp) ফোল্ডার ক্লিন করে।
*   `Prefetch` ফোল্ডার ক্লিন করে।
*   **অটোমেটিক অ্যাডমিন পারমিশন:** স্ক্রিপ্টটি নিজে থেকেই প্রয়োজনীয় পারমিশন চেয়ে নেয়।

## 🚀 কীভাবে ব্যবহার করবেন?
১. আপনার পিসিতে **Python** ইনস্টল করা থাকতে হবে (না থাকলে python.org থেকে করে নিন)।
২. `clean-win-temp.py` ফাইলটি ডাউনলোড করুন।
৩. ফাইলটির ওপর ডাবল ক্লিক করুন।
৪. একটি পপ-আপ আসবে (UAC), সেখানে **Yes** দিন।
৫. কাজ শেষ হওয়া পর্যন্ত অপেক্ষা করুন এবং শেষে `Enter` চাপুন।

## ⚠️ সতর্কতা
*   এটি ফাইলগুলো স্থায়ীভাবে ডিলিট করে দেয় (রিসাইকেল বিনে যায় না)।
*   যেসব ফাইল বর্তমানে কোনো সফটওয়্যারে ওপেন আছে, সেগুলো এটি ডিলিট করবে না (সেগুলোকে নিরাপদভাবে এড়িয়ে যাবে)।
*   স্ক্রিপ্টটি শুধুমাত্র ফাইল ডিলিট করার পারমিশন চায়। এটি কোনো নেটওয়ার্ক কল বা সেনসিটিভ ডেটা এক্সেস করে না।
